Terra Nova native - developer installation

Start Play.cmd. Keep this folder together and move it only while the game is closed.
Retail and Prequel switch in the same window and share preferences. Campaign saves stay under retail.
This unbundled developer installation lacks the launcher runtime required for exact Prequel F5/F9 snapshots.
Use a launcher-bundled player package for snapshot controls. Ordinary retail campaign saves remain available.
Use an ASCII destination of at most 115 characters. Distribution review and final acceptance remain in progress.

Unchanged resources may share storage with originals or other installations.
Treat them as read-only; use --data-mode copy during setup before editing assets.
Saves, settings and generated resources remain independent.
